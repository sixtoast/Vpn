# Karoo VPN — PWA dashboard

A mobile-first installable PWA dashboard for a single South African WireGuard endpoint.

## Important distinction
This repo provides the dashboard, not a running VPN service. A PWA cannot create or toggle an iOS system VPN tunnel. Install the official WireGuard app on iPhone and import a client profile generated by your own server. The UI deliberately does not pretend that tapping a button connects a tunnel.

## Free server reality
A free South African VM is not guaranteed. Cloud free tiers depend on region eligibility, capacity, account checks and provider terms. Confirm that the VM's actual public IP is allocated in South Africa before relying on it. Static PWA hosting does not host a VPN server.

## Deploy the dashboard
Host the contents of this directory on any HTTPS static host. HTTPS is required for service workers and normal PWA installation. Do not put WireGuard private keys, client configs, passwords or server credentials in this repository.

## Next steps for a real VPN
1. Provision an Ubuntu VM whose datacentre and public IP are confirmed to be in South Africa.
2. Confirm root access, kernel support, public IPv4, and that UDP 51820 is allowed by the provider firewall.
3. Install and configure WireGuard on the VM; enable IPv4 forwarding and NAT; review firewall rules before enabling the interface.
4. Generate a unique key pair and client config per device. Keep all private keys off GitHub and out of the PWA.
5. Import the profile into the official WireGuard iOS app, connect, then check the public IP and DNS/IPv6 leak behaviour.
6. Configure on-demand/kill-switch behaviour in the VPN app if required. The sample dashboard currently cannot verify live tunnel state.

## Limitations
This is a starter UI, not audited VPN software. No server has been provisioned and no live connection is bundled. A VPN changes your network route; it does not make you anonymous.
